  1. Open Google Firebase Console and sign in with your Google account.
  2. Click Add project and name it e.g. rania-classroom.
  3. From the left navigation, select Firestore Database and click Create Database.
  4. Under Project settings, copy your API Key and Project ID and paste them above.
